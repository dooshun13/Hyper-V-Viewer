Warning ID 153 · SRV-APP01

Disk 3 had to retry a read/write

10 Nov 2026 · 23:41:10 · System › disk
What it means
Windows sent a request to Disk 3 that did not complete in time, so it tried again. One retry is harmless; many in a short time point to a storage path problem.
Common causes
Failing or overloaded disk · storage controller or driver problem · on a VM, a slow datastore on the host.
Look next
13 retries in 5 minutes, then the server restarted unexpectedly at 23:52 with a blue screen. Check Disk 3 health and the storage driver, then open the memory dump.
