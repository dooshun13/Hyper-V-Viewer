# Hyper-V Viewer v1 — Build Plan

**Spec:** `docs/superpowers/specs/2026-11-13-hvviewer-v1-design.md` (the source of truth). `CLAUDE.md` holds the non-negotiable rules.
**Tracking:** each task below has a GitHub Issue with the same number and title (label `plan`). Close the issue in the commit that finishes the task (`Closes #N`).

## How to use this plan (for Claude Code)

1. Read `CLAUDE.md` and the spec first.
2. Do the tasks **in order**. A task can start only when the tasks it depends on are closed.
3. Work test-first: write the failing tests listed under **Tests**, make them pass, then refactor.
4. A task is done only when **every acceptance criterion** is met and CI (`.github/workflows/ci.yml`, Windows runner) is green.
5. One commit (or a short series) per task, with a clear message ending in `Closes #N`.
6. If a requirement turns out wrong or impossible (for example an event ID or channel name that does not exist on a real host), **stop and ask the owner**. Don't quietly change the design.
7. You cannot click through the WPF UI in CI. For UI work, keep logic in view-models and test it there; describe anything that needs a manual check in the task's issue when closing it.

## Task 2 — Resource guard: limits, priority, parallel readers

**Goal:** the app is light on a busy production host (spec §4).

**Requirements**
- Add `src/HvViewer.Core/Safety/ResourceLimits.cs`: `public sealed record ResourceLimits(int MaxEvents = 500_000, long MaxManagedBytes = 1L << 30)` with a `Default` instance.
- Add `src/HvViewer.Core/Safety/ResourceGuard.cs`: built from `ResourceLimits` and a `Func<long>` that returns managed memory (default `() => GC.GetTotalMemory(false)`), so tests can fake memory. Method `string? Check(int eventsRead)` returns `null` while under the limits, or a user-facing reason:
  - `"Stopped at the 500,000-event limit: narrow the time range or the logs"`
  - `"Stopped at the 1 GB memory limit: narrow the time range or the logs"`
- **SearchService:** take an optional `ResourceGuard` (default: `new ResourceGuard(ResourceLimits.Default)`). Check after every event read (cheap) or every batch; when it returns a reason, add `new SkippedLog("(limit)", reason)` to the skipped list, flush the hits found so far, send the final update with `Completed: true`, and stop reading.
- **DashboardService:** same guard, counting events across all logs. On a limit, record the reason in `skipped`, stop scanning further logs, and return the result built from what was read.
- **NativeEventSource:** `TextParallelism` becomes a constant `2` (spec: at most 2 parallel readers). Update its comment.
- **App start-up** (`App.xaml.cs`, `OnStartup`): set `Process.GetCurrentProcess().PriorityClass = ProcessPriorityClass.BelowNormal` inside a `try`/`catch` for `Win32Exception` and `InvalidOperationException` (never crash for this).
- Existing behaviour under the limits must not change.

**Tests** (`tests/HvViewer.Tests/Core/ResourceGuardTests.cs`, plus additions to `SearchServiceTests` and `DashboardServiceTests`)
- Guard returns `null` under both limits; returns the event reason at `MaxEvents`; returns the memory reason when the fake memory passes `MaxManagedBytes`.
- Search with a guard of `MaxEvents = 3` over 10 events: stops, keeps the hits from the first 3, `Completed` is true, `Skipped` contains the limit reason.
- Dashboard with `MaxEvents = 2` over three logs: result has the limit reason in `Skipped` and was built from the events read.

**Acceptance criteria**
- All new and existing tests pass.
- No limit is a user setting in v1 (constants only).

## Task 4 — Channel names: spelling-tolerant matching and Hyper-V channel list

**Goal:** rules and the dashboard work whether a host spells a channel `…-Admin` or `…/Admin` (spec §5.1).

**Requirements**
- Add `src/HvViewer.Core/Logs/ChannelName.cs`:
  - `static bool Same(string a, string b)`: case-insensitive, and treats `/` and `-` as equal **only at the separator before the last segment** (`Microsoft-Windows-Hyper-V-Worker-Admin` == `Microsoft-Windows-Hyper-V-Worker/Admin`). Identical strings are always equal.
  - `static string? OtherSpelling(string name)`: for a name ending in `-Admin`, `-Operational`, `-Networking`, `-Storage` return the `/` form, and the reverse; otherwise `null`.
- Add `src/HvViewer.Core/Logs/HyperVChannels.cs`:
  - `const string Prefix = "Microsoft-Windows-Hyper-V-"` and `const string Cluster = "Microsoft-Windows-FailoverClustering/Operational"`.
  - `static IReadOnlyList<string> Known` with the spec §5.1 list.
  - `static bool IsHyperV(string channel)`: starts with the prefix (case-insensitive) or is the cluster channel.
  - `static IReadOnlyList<string> Installed(IReadOnlyList<ChannelInfo> channels)`: the installed, enabled Admin/Operational channels for which `IsHyperV` is true, sorted.
- **RuleSet:** `Match` and `EventsForLog` compare logs with `ChannelName.Same` instead of `string.Equals`.
- **DashboardService:** when reading a rule log throws `LogNotFoundException` and `OtherSpelling` gives a name, try that name once before recording it as skipped.
- **DashboardAnalyzer:** tile "unavailable" logic must still work when the other spelling was used (compare with `ChannelName.Same`).

**Tests**
- `ChannelNameTests`: same/different cases, case-insensitivity, `OtherSpelling` both ways, `null` for `System` and `Microsoft-Windows-GroupPolicy/Operational`.
- `HyperVChannelsTests`: `Installed` keeps Hyper-V and cluster channels, drops others, drops disabled and Analytic/Debug.
- `DashboardServiceTests`: a rule on `X-Admin`, fake source has only `X/Admin` → events are read and matched; tile is not unavailable.
- Existing `RuleSet` / dashboard tests still pass.

**Acceptance criteria**
- All tests pass; no behaviour change for the 11 existing troubleshooters.

## Task 8 — VM inventory (read-only WMI)

**Goal:** read the host's VMs safely (spec §5.3).

**Requirements**
- In `src/HvViewer.System/HyperV/` (namespace `HvViewer.Machine.HyperV`):
  - `VmInfo` record: `Guid Id`, `string Name`, `VmState State`, `VmHealth Health`, `TimeSpan? Uptime`, `int? VirtualProcessors`, `long? StartupMemoryMb`, `bool? DynamicMemory`, `int? Generation`, `string? ConfigurationVersion`.
  - `VmState` enum and `VmStateText.FromEnabledState(ushort)`: 2 Running, 3 Off, 32768 Paused, 32769 Saved, 32770 Starting, 32771 Checkpointing, 32773 Saving, 32774 Stopping, 32776 Pausing, 32777 Resuming, anything else Other.
  - `VmHealth` enum and `FromHealthState(ushort)`: 5 OK, 20 Major failure, 25 Critical failure, anything else Unknown.
  - `Generation` from `VirtualSystemSubType`: `Microsoft:Hyper-V:SubType:1` → 1, `…:2` → 2.
  - `VmIdFromInstanceId(string)`: parses `Microsoft:<GUID>\…` (also `Microsoft:<GUID>`), returns `Guid?`.
  - `HyperVInventoryResult`: `Status` (`Ok`, `NotInstalled`, `AccessDenied`, `Error`), `IReadOnlyList<VmInfo> Vms`, `string? Message`.
  - `IHyperVInventory` with `HyperVInventoryResult Read()`.
  - `HyperVInventoryMerger` (pure): merges raw rows (computer systems, settings, processor settings, memory settings as simple DTOs) into `VmInfo` by VM ID. Settings rows whose ID matches no VM are ignored (checkpoints have their own IDs).
  - `WindowsHyperVInventory : IHyperVInventory` (`[SupportedOSPlatform("windows")]`): scope `root\virtualization\v2`, **WQL `SELECT` only** with the exact queries in spec §5.3, then the merger. Map errors: namespace not found (`ManagementException` with `InvalidNamespace`) → `NotInstalled`; `UnauthorizedAccessException` or `AccessDenied` → `AccessDenied` with message "Run as administrator or join the Hyper-V Administrators group"; anything else from WMI/COM → `Error` with the message. Never throw.
- No WMI method calls (the Task 3 safety test must stay green).

**Tests** (`tests/HvViewer.Tests/Machine/HyperV/`)
- State, health, generation mappings (theory data for every value above).
- `VmIdFromInstanceId`: with and without a suffix, braces, bad input → null.
- Merger: two VMs, settings for both plus one checkpoint row → two `VmInfo` with the right vCPUs/memory; a VM with no settings rows keeps nulls.
- A `[WindowsFact]` smoke test that `WindowsHyperVInventory.Read()` returns without throwing (any status).

**Acceptance criteria**
